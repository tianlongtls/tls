國中升學管道完整解析

國中畢業不是升學的終點，而是人生下一階段的起點。 從高中、高職到五專，了解多元入學制度， 依照孩子的學習能力、興趣與未來目標，找到最適合自己的升學道路。

國中升學，選對方向比盲目追求分數更重要！
了解國中教育會考、免試入學、直升入學、特色招生及五專升學制度，提早做好升學準備。
PATH 01

🎓 高中職免試入學

最主要的升學管道

國中畢業生依照所屬免試就學區規定，選填普通高中、技術型高中及綜合高中志願，依招生名額與超額比序規定進行分發。

  • 參考國中教育會考成績。
  • 重視志願序及多元學習表現。
  • 依各就學區超額比序規定辦理。
PATH 02

🏫 直升入學

國中部直升高中部

部分設有高中部的學校，依招生規定提供國中部應屆畢業生直升高中部的機會，讓學生在熟悉的學習環境中延續學習。

  • 須符合學校當年度直升資格。
  • 依核定招生名額及相關規定辦理。
  • 報名前應確認直升與其他入學管道的規定。
PATH 03

🌟 優先免試入學

提早爭取理想學校

部分就學區或學校辦理優先免試入學，依招生簡章規定提供學生優先選擇學校的機會。

  • 招生學校及名額依當年度簡章。
  • 依各區規定辦理報名及比序。
  • 留意錄取後報到及其他管道限制。
PATH 04

📚 完全免試入學

依招生方案申請

部分高中職學校辦理完全免試入學，依各校核定招生方案及簡章進行招生，不採計國中教育會考成績。

  • 招生學校及名額有限。
  • 依各校招生規定採計相關項目。
  • 應確認報名資格與放榜時程。
PATH 05

🏆 特色招生與技優甄審

專長與適性發展

針對具備特殊專長、技藝能力或學科潛能的學生，部分學校提供特色招生甄選或考試分發等機會。

  • 藝術才能班、體育班等專長招生。
  • 特色招生專業群科甄選。
  • 技藝教育競賽及技優甄審資格。
PATH 06

🧑‍🔬 五專多元入學

提早培養專業技能

國中畢業後可選擇五年制專科學校，透過專業課程、實習及技能培育，建立未來就業與繼續升學的基礎。

  • 五專完全免試入學。
  • 五專優先免試入學。
  • 五專聯合免試入學。

國中升學常見問題 FAQ

Q1：國中畢業一定要參加教育會考嗎？

國中教育會考是重要的學力檢測，但並非所有招生管道都採計會考成績。例如部分完全免試及其他專案招生有不同規定，應依當年度簡章確認。

Q2：國中畢業可以直接升讀原校高中部嗎？

若學校設有高中部且辦理直升招生，學生須符合當年度招生資格及相關規定，並依規定完成報名與錄取程序。

Q3：讀高職以後還可以考大學嗎？

可以。技術型高中畢業生可依規定參加四技二專統一入學測驗、甄選入學及其他升學管道，也有機會進入科技大學或其他大學。

Q4：五專和普通高中有什麼不同？

普通高中以學術課程及大學升學準備為主；五專則以五年專業教育、實習及技能培育為特色，適合專業興趣與職涯方向較明確的學生。
