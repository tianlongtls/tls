國中升學管道完整解析

國中畢業不是升學的終點，而是人生下一階段的起點。 從高中、高職到五專，了解多元入學制度， 依照孩子的學習能力、興趣與未來目標，找到最適合自己的升學道路。

國中升學，選對方向比盲目追求分數更重要！
了解國中教育會考、免試入學、直升入學、特色招生及五專升學制度，提早做好升學準備。
PATH 01

🎓 高中職免試入學

最主要的升學管道

國中畢業生依照所屬免試就學區規定，選填普通高中、技術型高中及綜合高中志願，依招生名額與超額比序規定進行分發。

  • 參考國中教育會考成績。
  • 重視志願序及多元學習表現。
  • 依各就學區超額比序規定辦理。
PATH 02

🏫 直升入學

國中部直升高中部

部分設有高中部的學校，依招生規定提供國中部應屆畢業生直升高中部的機會，讓學生在熟悉的學習環境中延續學習。

  • 須符合學校當年度直升資格。
  • 依核定招生名額及相關規定辦理。
  • 報名前應確認直升與其他入學管道的規定。
PATH 03

🌟 優先免試入學

提早爭取理想學校

部分就學區或學校辦理優先免試入學，依招生簡章規定提供學生優先選擇學校的機會。

  • 招生學校及名額依當年度簡章。
  • 依各區規定辦理報名及比序。
  • 留意錄取後報到及其他管道限制。
PATH 04

📚 完全免試入學

依招生方案申請

部分高中職學校辦理完全免試入學，依各校核定招生方案及簡章進行招生，不採計國中教育會考成績。

  • 招生學校及名額有限。
  • 依各校招生規定採計相關項目。
  • 應確認報名資格與放榜時程。
PATH 05

🏆 特色招生與技優甄審

專長與適性發展

針對具備特殊專長、技藝能力或學科潛能的學生，部分學校提供特色招生甄選或考試分發等機會。

  • 藝術才能班、體育班等專長招生。
  • 特色招生專業群科甄選。
  • 技藝教育競賽及技優甄審資格。
PATH 06

🧑‍🔬 五專多元入學

提早培養專業技能

國中畢業後可選擇五年制專科學校，透過專業課程、實習及技能培育，建立未來就業與繼續升學的基礎。

  • 五專完全免試入學。
  • 五專優先免試入學。
  • 五專聯合免試入學。

天龍教育國中部｜課程常見問題 FAQ

Q1：天龍國中部適合哪些學生？

天龍教育國中部重視學科基礎、觀念理解與學習成效。 無論是希望穩定學校成績、加強弱科， 或提前為國中教育會考做好準備的學生， 都可以依照自己的學習需求， 了解天龍適合的課程安排。

Q2：國中數學成績不理想，天龍如何幫助學生進步？

國中數學最重要的是觀念扎根，而不只是大量刷題。 天龍重視數學觀念講解、題型分析與課後輔導， 協助學生找出學習盲點，逐步建立解題能力， 讓數學不再只是死背公式。

Q3：國中英文單字背不起來、文法不熟，天龍如何加強？

國中英文需要長期累積，從單字、文法到閱讀理解 都不能忽略。天龍重視英文基礎與系統化學習， 透過課堂講解、練習與重點複習， 幫助學生建立英文實力， 為段考與教育會考做好準備。

Q4：學校段考範圍多，天龍如何協助學生準備？

面對國中各次段考，天龍強調平時觀念建立 與考前重點複習，協助學生掌握重要單元、 常見題型與容易失分的觀念， 讓複習更有方向，而不是考前才匆忙準備。

Q5：國三教育會考，天龍如何協助學生準備？

國中教育會考不只考驗國三課程， 更重視國一到國三的整體學科能力。 天龍重視基礎觀念統整、重點複習與題型練習， 協助學生逐步累積應考實力， 朝自己的升學目標努力。

Q6：為什麼三峽、北大特區家長可以考慮天龍國中部？

選擇國中補習班，除了師資與課程， 更要重視學生是否真正理解與吸收。 天龍教育重視教學品質、學習狀況與課業輔導， 希望讓每位學生不只是聽懂課程， 更能逐步建立獨立思考與解題能力。
