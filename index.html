PATH 01

特殊選才

用獨特經歷與能力，開啟升學可能。

這是什麼制度？

由各大學依自身特色辦理招生，重視特殊才能、經歷、成就或潛力；各校系可採書面審查、面試、實作等方式選才。

  • 適合誰：在競賽、研究、創作、社會實踐或特定領域有突出表現，且符合校系資格者。
  • 準備重點：成果證明、個人經歷、學習動機、作品集及面試。
  • 留意：不是所有校系都有名額；資格、時程與甄選方式依各校簡章。
天龍提醒：提早整理具體成果，讓資料清楚說明「做過什麼、學到什麼」。
PATH 02

繁星推薦

穩定的高中學習表現，是重要的競爭優勢。

這是什麼制度？

由高中依規定推薦符合資格的應屆畢業生，主要考量在校學業成績全校排名百分比，並依校系規定檢定學測、英聽或術科等成績。

  • 適合誰：高一到高三上成績穩定、校內排名具優勢者。
  • 準備重點：維持校內成績、確認排名與推薦資格、留意校系檢定標準。
  • 留意：校內推薦規則、學群限制與錄取規定須詳閱當年度簡章。
天龍提醒：繁星不只看高三，平時每一學期的成績都很重要。

PATH 03

個人申請

用成績、學習歷程與甄試，展現個人特色。

這是什麼制度？

通常先以學測等校系指定條件進行第一階段篩選，通過後參加第二階段甄試，可能包含審查資料、面試、筆試或實作等。

  • 適合誰：對目標科系有興趣，能具體呈現學習經驗與能力者。
  • 準備重點：學測、學習歷程檔案、修課成果、多元表現、面試。
  • 留意：各系採計項目與比重不同，須依當年度簡章確認。
天龍提醒：資料重質不重量，重點在成果、反思與科系連結。

PATH 04

考試分發

以考試實力與志願策略，爭取理想校系。

這是什麼制度？

依各校系採計的學測、分科測驗或術科等成績及相關規定，配合考生志願序進行統一分發。

  • 適合誰：擅長考試、希望透過分科測驗提升校系選擇機會者。
  • 準備重點：確認校系採計科目、準備分科測驗、評估落點與志願排序。
  • 留意：檢定、加權及採計方式依校系不同；其他管道錄取資格可能影響報名。
天龍提醒：選考科目與志願策略同樣重要，別只看單一總分。

常見問題 FAQ

特殊選才一定要有競賽得獎才能報名嗎？

不一定。各校系條件不同，可能重視研究、創作、特殊經歷或其他潛力證明，應以招生簡章為準。

繁星推薦是不是只看學測成績？

不是。繁星重視在校學業成績全校排名百分比，學測等成績則依校系規定作為檢定或相關比序依據。

個人申請是不是只要準備學習歷程？

不是。通常還須符合第一階段學測等篩選條件，第二階段也可能包含面試、筆試或實作。

個人申請錄取後還能參加考試分發嗎？

須依當年度規定在期限內完成放棄錄取資格等程序，否則可能不得參加分發入學。請務必查閱正式簡章。

哪一種入學方式最好？

沒有適合所有人的單一答案。應綜合校內排名、學測與分科實力、個人專長、科系志向及當年度招生規則判斷。
