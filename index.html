PATH 01

特殊選才

用獨特經歷與能力，開啟升學可能。

這是什麼制度？

由各大學依自身特色辦理招生，重視特殊才能、經歷、成就或潛力；各校系可採書面審查、面試、實作等方式選才。

  • 適合誰：在競賽、研究、創作、社會實踐或特定領域有突出表現，且符合校系資格者。
  • 準備重點：成果證明、個人經歷、學習動機、作品集及面試。
  • 留意：不是所有校系都有名額；資格、時程與甄選方式依各校簡章。
天龍提醒：提早整理具體成果，讓資料清楚說明「做過什麼、學到什麼」。
PATH 02

繁星推薦

穩定的高中學習表現，是重要的競爭優勢。

這是什麼制度？

由高中依規定推薦符合資格的應屆畢業生，主要考量在校學業成績全校排名百分比，並依校系規定檢定學測、英聽或術科等成績。

  • 適合誰：高一到高三上成績穩定、校內排名具優勢者。
  • 準備重點：維持校內成績、確認排名與推薦資格、留意校系檢定標準。
  • 留意：校內推薦規則、學群限制與錄取規定須詳閱當年度簡章。
天龍提醒：繁星不只看高三，平時每一學期的成績都很重要。
PATH 03

個人申請

學測成績結合學習歷程，展現個人特質。

這是什麼制度？

採計學測成績作為第一階段篩選，通過後進入第二階段指定項目甄試（包含面試、筆試、實作或書面審查學習歷程檔案）。

  • 適合誰：學測成績達標、能清楚表達學習熱情與科系適性者。
  • 準備重點：學測各科穩定表現、學習歷程檔案整理與第二階段面試演練。
天龍提醒：提早熟悉目標校系審查重點，讓學習歷程呈現個人亮點。
PATH 04

考試分發

以分科測驗成績為後盾，全力衝刺理想志願。

這是什麼制度？

依據分科測驗及學測採計科目成績，配合加權計分與志願序進行全國統一分發。

  • 適合誰：擅長筆試、希望透過考試成績做最後衝刺與穩健分發者。
  • 準備重點：分科測驗學科複習、考古題演練及落點分析與志願策略。
天龍提醒：保持各科實力均衡，分科測驗是另一個翻轉與大展身手的機會。

天龍教育高中部｜課程與升學常見問題 FAQ

Q1：高一開始就需要補習嗎？天龍如何協助高中課程銜接？

高中課程的深度與進度和國中明顯不同，尤其數學、 英文與自然科更重視觀念整合。天龍教育高中部重視 高一基礎建立、段考準備與學習方法調整， 協助學生適應高中課程，為高二、高三及學測累積實力。

Q2：高中數學很難，天龍數學如何幫助學生提升成績？

高中數學不只是熟記公式，更需要理解觀念、 掌握題型與培養邏輯思考。天龍數學重視系統化教學、 觀念拆解、題型訓練與課後輔導， 協助學生找出學習盲點，逐步提升解題能力， 兼顧學校段考與學測準備。

Q3：高中英文單字量大、閱讀題目難，天龍 Robert 老師如何教學？

天龍高中英文 Robert 老師重視單字累積、 文法理解、長篇閱讀與英文寫作。 透過系統化教學、閱讀題型分析及寫作練習， 協助學生建立高中英文實力， 不只準備校內段考，更以學測英文為長期目標。

Q4：高中自然科內容複雜，天龍如何協助學生學習？

高中自然科重視科學觀念、圖表判讀與跨單元整合。 天龍以理解核心概念、掌握重要題型與學習檢核 為方向，協助學生整理學科重點， 建立面對高中自然課程與學測題目的應用能力。

Q5：高中段考成績不理想，天龍如何協助學生改善？

段考成績不理想，可能來自觀念不清楚、 練習不足或讀書方法不適合。 天龍重視平時學習追蹤、課後輔導與考前重點複習， 協助學生找出問題，調整學習節奏， 逐步穩定校內成績。

Q6：高中學測應該從高幾開始準備？天龍如何規劃？

學測準備不是高三才開始。 天龍強調高一建立基礎、高二深化學科能力、 高三進行總複習與考試策略調整。 透過階段式學習規劃，協助學生穩定累積實力， 避免考前才匆忙補救。

Q7：想透過繁星推薦上大學，天龍可以提供哪些協助？

繁星推薦重視高中在校學業成績全校排名百分比， 並須符合校系相關條件。 天龍重視高中各階段的段考表現與學習管理， 協助學生建立穩定的讀書習慣， 並透過升學資訊整理，讓學生及家長 提早了解繁星推薦的準備方向。

Q8：學測成績與學習歷程哪個比較重要？天龍如何協助升學規劃？

不同大學校系的採計與甄選方式不盡相同。 天龍提醒學生除了累積學測實力， 也應重視校內學習成果、學習歷程及個人興趣探索， 提早了解繁星推薦、個人申請與考試分發等升學管道， 選擇適合自己的方向。

Q9：為什麼三峽、北大特區的高中生可以考慮天龍教育？

天龍教育深耕三峽與北大特區， 重視優質師資、學習管理與課後輔導。 除了學科知識，更希望掌握學生的學習狀況， 協助學生釐清問題、建立讀書方法， 讓高中三年的努力更有方向。

Q10：天龍高中部如何協助學生朝理想大學邁進？

天龍教育高中部重視從高一到高三的完整學習規劃， 結合學科教學、課後輔導、段考準備、 學測複習與升學資訊， 協助學生依照自身程度與目標安排學習方向， 逐步累積進入理想大學的競爭力。
